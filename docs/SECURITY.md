# 安全与数据边界

CloudHelm 的审核用于降低 Agent 误操作风险，不能替代服务器权限、备份和恢复措施。当前实现及验证边界见 [STATUS.md](STATUS.md)。

## 三档审核

所有 Agent 命令和文件变更按固定顺序处理：

1. 身份、凭据与硬禁令；再检查主机的禁止读取／禁止写入路径。
2. 解析命令和目标，识别已知只读、普通写入、高影响及不透明操作。
3. 按当前对话的当前主机档位决定自动执行、独立审核或人工询问。
4. 执行前再次核验授权、操作内容、策略和终端控制权。

| 操作 | 第一档：重要操作询问，新主机默认 | 第二档：AI 审核 | 第三档：完全访问 |
| --- | --- | --- | --- |
| 命中硬禁令／保护清单 | 拒绝 | 拒绝 | 拒绝 |
| 已知只读与范围明确的普通写入 | 自动执行 | 自动执行 | 自动执行 |
| 高影响命令或敏感配置文件变更，如访问控制或大范围删除 | 逐次人工批准 | 独立 AI 审核：明确授权且有界可允许，不确定／重要转人工 | 逐次人工批准 |
| 效果不透明的有效命令 | 逐次人工批准 | 独立审核决定允许、转人工或拒绝 | 自动执行 |

主机设置是新对话默认值；输入框切换只影响当前对话的当前主机，重启后保持。已有主机和对话在升级时保留原有效档位，旧保护路径同时迁移到禁止读取和禁止写入。普通配置编辑、依赖安装和服务重启可自动执行；高影响判断仍取决于具体目标。推荐普通 SSH 用户，需要提权时执行具体的 `sudo xxx`；用户自选 root 登录仍可使用。

Bash 分析覆盖命令链、替换、重定向与支持的包装命令，包括 `sudo`、`env`、有界 `su -c`。Git 全局选项与真正子命令共享分析，不能因前置 `-C`/无害 `-c` 降低已识别高影响；tar 创建/列出/解压分开解释，明确归档写目标进入设备、关键文件和方向性保护路径检查。env/sudo 的字面目录变换只作用于内层调用；子 Shell 不污染兄弟命令，不确定的条件、目录、身份或命名空间保留未知。完整度仅表示受支持参数的分析覆盖，不代表远端运行时安全证明。解析失败或安全组件故障时不放行。已识别的根目录大范围破坏、磁盘擦写及关键目录破坏等形式会被拒绝。

第二档对不透明及高影响操作显式选择当前对话模型、Jev 或指定模型，另起一次无工具权限的审核调用。脚本审查只给审核模型安全分类及脚本摘要，不直接传脚本源码；不足以确定效果时必须转人工。低置信度、不确定、超时、无效输出及故障转人工；明确拒绝只阻止当前操作，连续三次 AI 拒绝会暂停。用户可以对单次 AI 拒绝主动申请精确人工复核。Jev 没有提供具体理由时界面不会编造理由；不会在选定审核源故障时切换计费来源。

## 批准与执行

批准绑定完整操作、主机修订、目录、身份、策略版本和终端代次。审批卡显示询问原因、操作、主机、账号、目录、已知影响和恢复提示。主进程及 worker 管理权威状态，界面不能靠修改按钮状态授权操作。审批最长十分钟有效，只提供本次批准或拒绝；内容、策略或控制权变化后需要重新审核。断线重连时待审批卡从后端快照恢复，旧卡过期或重复提交无效。

远端已有脚本由 SFTP 只读检查小型普通文件，执行前再核对 SHA-256；改变 cwd 或上下文不能确定的脚本暂不使用入口目录下的文件作检查，以免审核错误内容。检查失败或不适用时按当前档位处理其不透明性，已识别的高影响不被第三档不透明放行覆盖。检查到执行之间仍存在远端文件被并发替换的竞争窗口。下载后直接执行、动态脚本、Shell 路径绕过和用户自定义包装器只能尽力识别，保护路径不是远端文件系统沙箱。第三档允许无法识别效果的不透明命令，但仍保留少数硬禁令及身份、凭据、审计底线。硬禁令没有审批卡破例入口，只能由用户在人工终端自行处理。

效果只读分类与自动放行分类分离：字面 `sudo`（可带单独的 `--`）包裹后端已证明的查询，经正常 SafetyGate 审核后可作事后核验证据，但不因此成为免审命令，也不能读取敏感/用户保护文件。目录/服务/诊断仍遵循各自窄语法；date/hostname设置形式不是查询。解析不确定、管道、重定向、身份/其他sudo选项不获此能力；既有受限cat/ls/stat字面列表按原规则处理。后端自动整理执行、目标观察、影响与登记状态，缺少模型报告不再要求反复提交。V3 可比较该次运行的完整捕获输出，文件内容按主机/路径/哈希读回匹配；这不证明没有其他影响，也不证明整个用户目标已实现。复杂语义明确标为模型判断。结果未知或可能部分生效的失败仍阻断，不以报告、聊天或目标通过替代写锁。显式轮次和追加报告历史保留旧的不确定性，普通新消息不构成风险接受，详见[验收 V3](VERIFICATION_V3.md)。

`run_remote.outputExpectation` 只是执行前绑定的输出比较条件，不参与放行或提升权限；实际运行观察自动登记，不要求另交报告。验收汇总可以区分“结构化证据确认未启动的尝试”和“同一脚本后续真实成功”，但不改写原尝试状态，不以普通非零退出、审核拒绝或可能部分生效的失败推断已恢复。`ls` 仍不是文件内容证据。

旧自动报告的离线重整只在主进程读取权威记录：完整预览必须匹配原意图摘要，按明确轮次顺序投影；活动／未决、不完整或变化的来源拒绝。入口不恢复 Runner、连接 SSH、读取凭据或请求模型；修订追加保留原报告，不修改原操作、风险接受或写锁。源码和 fixture 均归对应目录，自动测试统一在 [Tests/](../Tests/README.md)，生产禁止导入测试实现。

同主机未决远端结果是独立于三档审核的写锁：新命令即使已获审核允许也不会派发。用户在简明恢复卡按需展开旧操作和脱敏日志、尝试只读核验后，可逐项明确接管仍未知的风险；正在被追踪运行的命令不能解除。接管记录保留原未知状态，不构成新命令批准或成功验收。

人工在终端输入不受 Agent 审核档位约束。AI 运行期间拒绝普通终端输入；只有显式停止动作会撤销本轮权限并请求中断命令，命令退出后才开放输入。暂停模型请求、停止远端命令、关闭会话和断开连接是分别记录的动作。

## SSH 身份与连接测试

正常连接验证主机指纹；未知指纹需要用户通过可信渠道核对，指纹变化不能静默接受。

配置页测试使用独立连接，只验证网络和认证。测试中的指纹确认只对本次配置有效，不写入长期信任记录；跳板机和目标主机分别确认。确认令牌单次使用、两分钟过期，修改表单或凭据后失效。

已有凭据只在测试目标、账户和认证配置保持一致时复用。测试结果不包含密码、私钥内容或服务器返回的原始错误正文；只返回有限的状态和诊断类别。需要额外 keyboard-interactive 验证的测试会提示通过正常连接完成，不猜测答案。

## 密码与交互输入

提权默认使用具体sudo命令；`request_root_session`可准备逐命令sudo上下文，准备不运行探测或业务操作，不冒充已验证root登录。命令在审核前规范化，执行器不在批准后偷偷加sudo；备选root SSH或直接su必须用户明确确认，sudo/su不提升SFTP。失败反馈区分来源与业务启动边界，输出推断不能清除未决结果或成为换身份授权，详见[受控提权](privilege-contexts.md)。

SSH keyboard-interactive 通过 ssh2 的结构化认证回调回答。普通 sudo 命令直接启动目标程序，执行组件只增加标准 `-A` 认证选项，不把业务命令改写成 root Shell 脚本。密码弹窗通过操作专属 Unix socket 交给 sudo 的 askpass 子进程，绝不写入业务 PTY；重复或迟到的回答不能成为命令 stdin。`run_remote`直接提交的`su`、交互式root Shell和无法识别的认证形式仍需人工处理；专用工具的隔离su备选需明确root密码归属并验证UID，不自动转换成其他提权方式。

可静态解析的 sudo 前台命令列表保留分号、换行和条件连接的执行顺序；列表中每个进程单独启动，密码通道仅附加到当前 sudo。执行后续进程前再次检查操作授权和终端代次；人工接管、断线或结果未知时停止派发后续进程，不自动重放。

交互请求绑定操作、主机、连接和终端代次、接收方、类型及有效期。界面只提交请求 ID 和回答，不能另选接收终端。操作结束、阶段变化、断线、接管、超时和重复提交都会使旧请求失效。

经专属输入窗口提交的密码和验证码不进入模型上下文、工具参数、终端录制、审计正文或剪贴板。AI 只收到提交或验证失败等非敏感状态，默认不保存认证回答。用户在主机设置中主动保存的 SSH 凭据是独立功能，由 safeStorage 加密保存。

普通日志出现 `Password:` 不能单独触发索密。未知 PAM、密码修改、来源不明提示或无法确认安全投递的流程需要人工接管。自动处理 APT 确认只适用于能证明不增加删除等影响的情形；影响扩大时重新审核。

输入窗口说明当前操作和用途。取消输入、稍后填写或关闭窗口不自动终止远端进程，应通过单独的停止命令操作处理。

## 本地与远端文件

- AI 本地读取限于用户通过系统选择器授权的资料；主进程发放选择令牌，worker 核对真实路径与范围。没有开放任意本地 Shell。
- 私钥选择器仅用于 SSH 认证配置，不发放 AI 附件令牌。
- 上传绑定已选来源及内容摘要，提交前重新核验；结构化文件操作限 1 MiB 常规文件。
- SFTP 写入先使用临时文件，覆盖／删除尽力保存恢复副本；拒绝已识别的不安全父路径与符号链接。
- 原生会话的本地临时目录采用幂等清理与有限锁重试；终态失败发出固定类别警告，不记录目录路径、内容或原始异常，不删除持久会话存储。这不代表远端命令已被停止。
- 远端其他进程并发替换路径的场景不具备事务隔离保证。Shell 命令造成的任意系统变更没有通用自动回滚机制。

## 模型服务与隐私

| 数据 | 用途与接收方 |
| --- | --- |
| 对话目标、计划、摘要、操作结果及检索的日志片段 | 发给当前配置的主模型服务用于推理 |
| 脱敏后的拟执行命令或文件操作摘要、主机标识、账户、目录、分析信息及少量近期动作 | 发给显式选定的独立审核模型；文件正文不用于审核 |
| 主动选择并由工具读取的本地资料 | 可作为工具结果进入主模型上下文；结构化文件操作的审核只发送路径、大小等摘要 |
| 主动引用的普通终端输出 | 加入用户消息，随对话发给主模型 |
| SSH 密码、私钥口令和交互验证码 | 仅进入对应 SSH 认证／受支持的操作输入通道，不作为模型输入 |

普通终端输出不会自动注入 AI 对话。保存的终端日志会进行模式脱敏，但无法识别任意格式的敏感数据；不要把日志脱敏理解为完整匿名化。

模型凭据按供应商配置隔离，修改 Key 或地址会使旧对话凭据绑定过期。API Key 使用对应供应商的认证通道；用户设置自定义 Base URL 即决定该模型请求及凭据的目标地址。订阅 OAuth 未实现，不使用第三方应用的 OAuth 身份。

## 展示与故障边界

AI Markdown 禁用原始 HTML。代码块只提供复制；图片不会自动发起远程请求。可点击外链限定为不包含内嵌用户名／密码的 HTTP(S) 地址，并交给系统浏览器打开。

友好错误界面只显示识别过的固定原因与下一步，不原样展示可能夹带凭据的异常正文。SQLite 本地记录与凭据密文位于应用数据目录；日志默认保留 30 天，逻辑总量上限 5 GiB。

硬禁令不能证明任意编码脚本、动态加载内容或恶意远端环境安全。第三档允许未被识别为禁令的不透明脚本；本产品不是远端沙箱。规则、审核模型和脱敏都只能降低风险，不能替代远端最小权限与备份。源码研究和采纳边界见[权限设计研究](PERMISSION_RESEARCH.md)。

报告安全问题时提供最小复现、版本、预期／实际行为及已脱敏日志。不要在公开 Issue 或 PR 中附带生产凭据、真实私钥或未脱敏的用户数据库。

## 原生组件及文件提交边界

远端组件只从随包的已校验 ELF 清单选择，支持 Linux x64/arm64。默认 `/tmp` 私有目录，也可由用户明确指定目录；不能执行或被路径策略禁止时停止 Agent 操作，不自动换到另一个保护区域。安装、启动和清理具有独立的审核与资源记录。旧 Python 和 SFTP 文件写事务不再提供回退入口。

文件快照使用逐级目录句柄、O_NOFOLLOW、普通文件验证及 1 MiB＋1 有界读取。提交前绑定原对象、内容和属性，发现变化返回冲突。新建使用原子不覆盖；已有目标使用最后复核与原子替换，因此不能对非合作写入方提供强事务隔离。成功备份保留，未知事务不自动清理。

已有文件保存 uid/gid、mode、访问 ACL、受支持 xattr 与 SELinux 标签。setuid/setgid、文件能力、immutable/append-only、多硬链接及未知安全属性在替换前拒绝，无法保留普通属性也拒绝。扩展属性真实值只在远端内存复制，日志绑定属性摘要。cron、系统 systemd unit、系统和 root shell 执行入口在写入/上传/删除及已识别 Shell 修改中共享高影响规则。

旧内容只在受控审批预览中提供完整展开，不进入模型或普通审计正文。密码/验证码仅走专用敏感输入，服务器提示按未知类型处理，模型无权根据提示判定密码或OTP。缓存资格必须由后端结合用户明确选择与一次成功挑战判断。
