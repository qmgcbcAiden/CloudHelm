# 实现与验收状态

更新日期：2026-10-03。本文的代码验证基线为 `8a1c9fa`（增加主机配置测试连接与临时指纹核对）；后续纯文档提交不改变该基线的功能范围。新提交的构建结果应查看其自己的 Checks。

## 可复核的验证证据

### 自动检查

| --- | --- |

该工作流包含类型、代码规范、依赖和行数检查、Vitest、UI/Markdown 回归、Electron 编译后／打包后启动检查及 DMG／NSIS 生成。安装包 Artifact 保留七天，到期后可从对应提交重新构建。上面的链接仅证明该代码基线，不代替将来提交的验证。

本机标准 `pnpm check`：**297 项通过，3 项跳过**。跳过项需要显式临时本地 SSH 服务，不能计入默认通过数。新增的独立 loopback SSH 握手测试不需要生产服务器，覆盖指纹确认、密码认证、临时连接清理和已有连接隔离。

`test:ui` 使用假 SSH／模型，检查菜单、私钥选择、未保存配置测试、确认失效、终端交互与界面状态；它不是远端执行测试。`test:desktop:packaged` 使用真实 Electron、SQLite、WASM、safeStorage 和临时本地 SSH 服务；原生文件对话框的自动探针使用替身。

可选本地集成链路包含真实 PTY、SFTP、安装确认，以及真实 Pi SDK → 本地模型协议 fixture → SSH/SFTP 的多轮执行。协议 fixture 使用预设回答，不代表真实模型判断或部署能力。

### 原生界面实际检查

macOS arm64 上已打开打包应用，确认主机菜单五项完整浮出、编辑页显示私钥“选择文件”和“测试连接”。已实际打开 macOS 原生私钥文件选择窗口，并取消返回；没有为验证而读取、替换或保存用户真实私钥。

**Windows 原生文件选择窗口尚未手动实测。** Windows CI 的构建、启动和对话框替身测试不能写成用户手动验收；macOS x64 的完整人工验收也未完成。
